<h1 align="center">📧 Email Sender</h1>

<p align="center">
  Эффективная и простая в использовании платформа, которая упрощает процесс общения, позволяя отправлять электронные письма сразу нескольким получателям.
</p>

![EmailSenderDemo](https://github.com/KrishBharadwaj5678/EmailSender/raw/main/EmailSenderDemo.png)

## <img src="https://github.com/KrishBharadwaj5678/EmailSender/raw/main/assets/readme/features.gif" width="35"/> Возможности

| Возможность | Описание |
| ------------ | -------- |
| 📩 Массовая отправка писем | Отправка писем нескольким получателям одновременно |
| ✍️ Простое создание писем | Удобный интерфейс для написания и форматирования писем |
| ⚡ Быстро и эффективно | Быстрая отправка писем с минимальной настройкой |
| 🎯 Удобный интерфейс | Чистый и интуитивно понятный интерфейс на Streamlit |
| 🔐 Безопасная отправка | Использует протокол SMTP для надежной доставки писем |

## <img src="https://github.com/KrishBharadwaj5678/EmailSender/raw/main/assets/readme/gettingStarted.gif" width="35"/> Начало работы

### 1️⃣ Клонируйте репозиторий

```bash
git clone https://github.com/KrishBharadwaj5678/EmailSender.git
```

### 2️⃣ Перейдите в папку проекта

```bash
cd EmailSender
```

### 3️⃣ Установите зависимости

```bash
pip install -r requirements.txt
```

### 4️⃣ Запустите приложение

```bash
streamlit run app.py
```
