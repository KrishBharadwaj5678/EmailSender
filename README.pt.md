<h1 align="center">📧 Email Sender</h1>

<p align="center">
  Uma plataforma simples e eficiente que facilita sua comunicação, permitindo o envio de e-mails para vários destinatários ao mesmo tempo.
</p>

![EmailSenderDemo](https://github.com/KrishBharadwaj5678/EmailSender/raw/main/EmailSenderDemo.png)

## <img src="https://github.com/KrishBharadwaj5678/EmailSender/raw/main/assets/readme/features.gif" width="35"/> Recursos

| Recurso | Descrição |
| -------- | --------- |
| 📩 Envio de E-mails em Massa | Envie e-mails para vários destinatários de uma só vez |
| ✍️ Composição Simples | Interface intuitiva para escrever e formatar e-mails |
| ⚡ Rápido e Eficiente | Envie e-mails rapidamente com configuração mínima |
| 🎯 Interface Amigável | Design limpo e intuitivo desenvolvido com Streamlit |
| 🔐 Envio Seguro | Utiliza o protocolo SMTP para envio confiável de e-mails |

## <img src="https://github.com/KrishBharadwaj5678/EmailSender/raw/main/assets/readme/gettingStarted.gif" width="35"/> Primeiros Passos

### 1️⃣ Clone o Repositório

```bash
git clone https://github.com/KrishBharadwaj5678/EmailSender.git
```

### 2️⃣ Acesse o Diretório do Projeto

```bash
cd EmailSender
```

### 3️⃣ Instale as Dependências

```bash
pip install -r requirements.txt
```

### 4️⃣ Execute a Aplicação

```bash
streamlit run app.py
```
