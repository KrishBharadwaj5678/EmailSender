<h1 align="center">📧 Email Sender</h1>

<p align="center">
  複数の受信者に一度にメールを送信できる、シンプルで使いやすいメール送信プラットフォームです。
</p>

![EmailSenderDemo](https://github.com/KrishBharadwaj5678/EmailSender/raw/main/EmailSenderDemo.png)

## <img src="https://github.com/KrishBharadwaj5678/EmailSender/raw/main/assets/readme/features.gif" width="35"/> 主な機能

| 機能 | 説明 |
| ---- | ---- |
| 📩 一括メール送信 | 複数の受信者へ一度にメールを送信 |
| ✍️ 簡単なメール作成 | シンプルなインターフェースでメールを作成・編集 |
| ⚡ 高速・効率的 | 最小限の設定ですばやくメールを送信 |
| 🎯 使いやすいUI | Streamlitを使用した直感的で見やすいデザイン |
| 🔐 安全な送信 | SMTPプロトコルを利用した信頼性の高いメール送信 |

## <img src="https://github.com/KrishBharadwaj5678/EmailSender/raw/main/assets/readme/gettingStarted.gif" width="35"/> はじめに

### 1️⃣ リポジトリをクローン

```bash
git clone https://github.com/KrishBharadwaj5678/EmailSender.git
```

### 2️⃣ プロジェクトディレクトリへ移動

```bash
cd EmailSender
```

### 3️⃣ 必要なライブラリをインストール

```bash
pip install -r requirements.txt
```

### 4️⃣ アプリケーションを起動

```bash
streamlit run app.py
```
