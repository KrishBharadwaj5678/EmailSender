<h1 align="center">📧 Email Sender</h1>

<p align="center">
  An effective and easy-to-use platform that implifies your communication process by sending emails to many people at one time.
</p>

![EmailSenderDemo](https://github.com/KrishBharadwaj5678/EmailSender/raw/main/EmailSenderDemo.png)

## <img src="https://github.com/KrishBharadwaj5678/EmailSender/raw/main/assets/readme/features.gif" width="35"/> Features

| Feature               | Description                                    |
| --------------------- | ---------------------------------------------- |
| 📩 Bulk Email Sending | Send emails to multiple recipients at once     |
| ✍️ Easy Composition   | Simple interface to write and format emails    |
| ⚡ Fast & Efficient    | Quickly deliver emails with minimal setup      |
| 🎯 User-Friendly UI   | Clean and intuitive design using Streamlit     |
| 🔐 Secure Sending     | Uses SMTP protocol for reliable email delivery |

## <img src="https://github.com/KrishBharadwaj5678/EmailSender/raw/main/assets/readme/gettingStarted.gif" width="35"/> Getting Started

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/KrishBharadwaj5678/EmailSender.git
```

### 2️⃣ Navigate to the Project

```bash
cd EmailSender
```

### 3️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

### 4️⃣ Run the App

```bash
streamlit run app.py
```
